# 2026-10-21

## 移植到 NeoForge 26.3.0.95（4.1.0 基线）

编译与运行均通过，产物 `build/libs/Elemental-Reactions-NeoForge-4.1.0-26.3.jar`。

改动：
1. `gradle.properties`：`neo_version=26.3.0.1-beta` → `26.3.0.95`。
2. 配置类型改名（26.3.0.37-beta 起）：`ModConfig.Type.COMMON` → `LOCAL`，共 7 处——
   `ElementalCraft.java`、`ForcedItemConfig`、`ElementalVisualConfig`、
   `ElementalThunderFrostReactionsConfig`、`ElementalFireNatureReactionsConfig`、
   `ConfigAutoSync`（`ConfigTracker.INSTANCE.loadConfigs` 两处）。
3. `client/FrozenInputBlocker.java`：`org.lwjgl.glfw.GLFW` 已不在类路径（26.3 换 SDL），
   改为 `com.mojang.blaze3d.platform.InputConstants.KEY_ESCAPE/F2/F3/F5`。
4. 移除 421 处纯空白注释 `BUILDER.comment(" ");`（四个 config 文件）。
   原因：NeoForge 新版 `ModConfigSpec.BuilderContext.buildComment` 对「整条注释 isBlank」
   在 dev 抛 `IllegalStateException`、prod 只 warn 并提示未来会崩。多行注释里的单个 `" "`
   分隔行不受影响（allMatch(isBlank)=false），仍会输出成 `# ` 空行。
   → 代价：配置项之间不再有独立空行分隔，其余注释文本全部保留。
5. `neoforge.mods.toml`：neoforge 依赖由 `[${neo_version},)` 改为显式 `[26.3.0.37-beta,)`，
   避免低版本玩家装上新包后直接 NoSuchFieldError。

验证：
- `compileJava` / `build` 通过；
- `runServer` 冒烟：`Done (1.371s)`，5 个配置 `Config Loaded`，`Common Setup` 正常；
- 客户端渲染未验证（无显示环境）。

遗留观察：日志里的 `@OnlyIn used on class ...` 是 dev 期既有告警，与本次移植无关。
