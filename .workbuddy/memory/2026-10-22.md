## Git 走网络的坑（Windows + 代理）

- 直接 `git clone/push` 会报 `schannel: CRYPT_E_NO_REVOCATION_CHECK`，
  换 openssl 后端则报 `unable to get local issuer certificate`（环境代理会中间人解 TLS）。
- 可用组合：`GIT_SSL_NO_VERIFY=1`（默认 schannel 后端），能正常 ls-remote/fetch/push。
- 本机 `127.0.0.1:10808`（v2rayN）对 github.com 不通，只有 sandbox 默认代理可用。
- 临时远端不要写进 `.git/config`，用带 token 的 URL 直接 push，避免 token 落盘。
